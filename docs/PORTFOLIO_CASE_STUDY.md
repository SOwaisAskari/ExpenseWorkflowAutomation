# Expense Workflow Automation — Case Study

**Objective:** Demonstrate how a manual expense-request process can be represented as a trackable workflow.

**Implemented:** OPEX/CAPEX request creation, department-head review, finance review, approve/revert decisions, resubmission, dashboard summaries, and audit history.

**Technology:** C#, .NET 8, ASP.NET Core Web API, EF Core, SQLite, HTML, CSS, JavaScript, Swagger.

**Scope boundary:** The app uses illustrative rules and sample records. It is not an employer's original application or a production finance system.
